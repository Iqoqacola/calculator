# Calculator App

A simple, fast, and responsive calculator application built with **React** and **Vite**.

## 🚀 Features
* **Basic Operations:** Addition, Subtraction, Multiplication, and Division.
* **AC Feature:** All Clear button to reset calculations.
* **Modern Design:** Styled with **Tailwind CSS**.
* **Calculations:** Supports decimal numbers and chained operations.

## 🛠️ Tech Stack
* [React](https://react.dev/)
* [Vite](https://vitejs.dev/)
* [Tailwind CSS](https://tailwindcss.com/)
* Sass

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/iqoqacola/calculator-app.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```
